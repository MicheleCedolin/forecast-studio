# Example datasets of the browser page

Nine small datasets from the Monash Time Series Forecasting Archive, copied unchanged so that the page has something to
run without an upload. `index.json` lists them with the horizon and rounding the catalogue (`src/tsfstudio/data/catalog.yaml`)
uses for each.

Source: Godahewa, R., Bergmeir, C., Webb, G. I., Hyndman, R. J., & Montero-Manso, P. (2021). Monash Time Series Forecasting
Archive. *NeurIPS Datasets and Benchmarks*. https://forecastingdata.org/ (all files:
https://zenodo.org/communities/forecasting). Licence of every file below: Creative Commons Attribution 4.0 (CC BY 4.0).

| File | Zenodo record |
|---|---|
| `nn5_weekly_dataset.tsf` | https://doi.org/10.5281/zenodo.4656125 |
| `nn5_daily_dataset_without_missing_values.tsf` | https://doi.org/10.5281/zenodo.4656117 |
| `m1_yearly_dataset.tsf` | https://doi.org/10.5281/zenodo.4656193 |
| `m1_quarterly_dataset.tsf` | https://doi.org/10.5281/zenodo.4656154 |
| `m1_monthly_dataset.tsf` | https://doi.org/10.5281/zenodo.4656159 |
| `tourism_quarterly_dataset.tsf` | https://doi.org/10.5281/zenodo.4656093 |

| `covid_deaths_dataset.tsf` | https://doi.org/10.5281/zenodo.4656009 |

Larger datasets are not published with the page: download them from the archive and choose the file on the page.
