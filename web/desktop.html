Forecast Studio desktop

The full application for your computer. It opens in your web browser but runs entirely on your machine.

1 Download and start required

Windows 10 or 11, 64-bit. Python is included in the package; you do not need to install it.

Download the latest release
  1. On the release page, under Assets, download ForecastStudio-…-win64.zip (about 225 MB). The .sha256 file next to it lets you check the download.
  2. Unzip it to a folder outside OneDrive, for example C:\ForecastStudio.
  3. Double-click ForecastStudio.exe. A console window opens and the interface opens in your browser; the first start can take 10 to 20 seconds.
  4. The program is not signed, so Windows may say it is from an unknown publisher: choose More info, then Run anyway.
  5. To stop, press Quit application in the interface or Ctrl+C in the console.

Without anything else this gives every method except N-HiTS, N-BEATS and Chronos-Bolt, with the C++ and Python engines.

2 R, for the R engine optional

Install R only if you want results from the original R code (the forecast package by Hyndman and colleagues) rather than its C++ and Python counterparts. Nine methods can run on the R engine.

  1. Download R for Windows from CRAN and install it.
  2. Open R and install the two packages the engine uses: 
    install.packages(c("forecast", "jsonlite"))
  3. Tell Forecast Studio where R is. Open PowerShell and run, with your own R version and folder: 
    setx TSFSTUDIO_RSCRIPT "C:\Program Files\R\R-4.6.2\bin\Rscript.exe"
    If you installed R without administrator rights, the folder is %LOCALAPPDATA%\Programs\R\R-…\bin. Restart Forecast Studio afterwards.
  4. Check: in the Forecast Studio folder, ForecastStudio.exe engines should list the R engine as available.

CatBoost on the R engine also needs the catboost R package, which is not on CRAN. Install the same version the other engines use (1.2.10, about 90 MB) from the CatBoost release, in R:

install.packages("https://github.com/catboost/catboost/releases/download/v1.2.10/catboost-R-windows-x86_64-1.2.10.tgz",
                 repos = NULL, type = "source", INSTALL_opts = c("--no-multiarch", "--no-test-load"))

More in the CatBoost installation guide. CatBoost also runs on the C++ and Python engines without it, with the same forecasts.

3 Python, for the deep learning models optional

N-HiTS, N-BEATS and Chronos-Bolt need PyTorch, which would make the package several gigabytes, so they are not in the zip. To use them, run Forecast Studio from its source code:

  1. Install Python 3.12 from python.org (newer versions may lack ready-made packages).
  2. Download the source code: GitHub, Code, Download ZIP, and unzip it outside OneDrive.
  3. In PowerShell, in that folder: 
    powershell -ExecutionPolicy Bypass -File scripts\windows\setup_native.ps1
.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install -e ".[deep]"
  4. Start it with ForecastStudio.bat.

Chronos-Bolt downloads its pretrained weights from Hugging Face the first time it runs. On macOS and Linux there is no ready-made package; the same source installation works there with pip install -e ".[pyengine,deep]" and python -m tsfstudio app.
